# Basic und Pro

**ComfyOS ist kostenlos.** Basic ist keine Probeversion und hat kein Zeitlimit. Alle Plugins und alles, was du zum Steuern deines Zuhauses brauchst, sind dabei.

**Warum es Pro gibt:** Die Entwicklung kostet Zeit und Geld. Jede neue Funktion muss getestet werden und braucht manchmal neue Hardware. Mit Pro unterstützt du die Weiterentwicklung direkt und bekommst als Dank ein paar Extras: zusätzliche Flow-Bausteine und mehr Möglichkeiten, das eigene Zuhause zu optimieren.

**Pro ist eine Lifetime-Lizenz:** keine Abos, keine wiederkehrenden Kosten.

| Bereich | Basic | Pro |
|---|---|---|
| Geräte, Räume, Steuerung, Szenen mit Raumvarianten, Effekte, Hausszene | ✅ | ✅ |
| Alle Plugins, auch künftige und eigene | ✅ | ✅ |
| Gerätesperre, Heizroutinen, Zuhause/Abwesend | ✅ | ✅ |
| Stromverbrauch: jetzt, seit Datum, heute, je Gerät | ✅ | ✅ |
| Grundriss mit Wänden, Türen, Balkonen, Gerätegruppen | 1 Stockwerk, 6 Räume | mehrere Stockwerke, unbegrenzt viele Räume |
| Grundriss: Fenster, Heizkörper, Heatmap, eigene Gerätesymbole, Wettereffekte | – | ✅ |
| Flow | Basic-Bausteine, bis 5 aktive Flows | alle Bausteine, unbegrenzt |
| Verlauf und Diagramme | 7 Tage | 31 Tage |
| Energieauswertung: Verlauf je Gerät, CSV-Export | – | ✅ |
| Widget-Ansicht mit allen Widgets und Editor | 1 Seite | mehrere Seiten, Pro-Inhalte in Widgets |
| KI-Import für Heizpläne und Flows | Vorschau des Prompts | ✅ |
| Eigene Akzentfarbe | – | ✅ |
| Backup und Umzugspaket | ✅ | ✅ |

**Grundsätze:**

- Basic ist ein vollständiges Smart-Home-Dashboard, keine Probeversion.
- Pro-Funktionen bleiben sichtbar und tragen ein dezentes „Pro“.
- Läuft eine Lizenz aus, arbeitet ComfyOS als Basic weiter. Daten gehen nie verloren, und nichts wird gesperrt.
- Ein bezahlter Plan verliert nie eine Funktion.

**Lizenz hinterlegen:** unter *System → Lizenz*, als Schlüssel oder als Lizenzdatei. Eine Lizenzdatei funktioniert ganz ohne Internet. Ein Schlüssel wird etwa alle 24 Stunden geprüft und hält 14 Tage ohne Verbindung durch.
